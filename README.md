## Overview

This entry generates a single funny, punchy one-liner about a meeting that should have been an email:
> "A 30-person meeting where two people talk and 28 unmute in unison to chorus 'Thanks everyone, bye!'"

It captures the universal corporate ritual of the synchronized unmute chorus with zero filler words, maximum economy, and an immediate comedic landing.

## How to Run

Run the script using Python 3:

```bash
python3 main.py
```

The script strips trailing whitespace, validates that the entry is a single line, writes it to `/output/entry.txt` (encoded as UTF-8), validates that the final written text is 1-200 characters, and prints the line and its character count to standard output.
